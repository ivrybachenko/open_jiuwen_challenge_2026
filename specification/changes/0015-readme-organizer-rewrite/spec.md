## Зачем

README вырос до 309 строк и смешал ответы на вопросы регламента с историей
версий, экспериментами и внутренними деталями. Организатору нужны пять
ответов: что это, как собрать и запустить, в чём идея харнесса, откуда
датасет и какой ИИ использовался. Остальное — ссылками.

Отдельно нужно раскрыть использование ИИ: 192 из 240 задач и весь код
созданы с LLM-агентами. Без явного раздела проверяющий не может отличить
сгенерированные артефакты от ручных и оценить, как они проверены.

## Что меняется

1. `README.md` получает ровно пять разделов: «Краткое интро», «Команды для
   сборки и запуска», «Ключевые идеи харнесса», «Особенности создания
   датасета», «Разглашение использования ИИ».
2. Учёт расхода, выбор задач для второй волны, невыполнимые задачи и
   траектории остаются в README, но внутри «Ключевых идей», без отдельных
   разделов.
3. Добавляется раздел о создании датасета: состав, происхождение задач,
   проверки при генерации, защита от утечки меток, доля нерешаемых.
4. Добавляется раздел об использовании ИИ: разработка, датасет, рантайм,
   чего ИИ не делает, ограничения.
5. `specification/behavior/09_readme.md` фиксирует новый набор обязательных
   разделов, вопросов, запрещённого содержимого и проверок; лимит объёма
   поднимается со 160 до 220 строк.
6. Ссылки в `specification/behavior/README.md` ведут на новые якоря README.

## Ограничения

- Регламент соревнования — источник истины; README не обещает того, чего нет
  в коде.
- `behavior/` остаётся источником истины о текущем поведении; README
  ссылается на него.
- Цифры замеров приводятся одной строкой с выводом и ссылкой, без таблиц.
- Раскрытие использования ИИ должно быть фактическим: без оценок и
  обещаний, которых нельзя проверить по репозиторию.
