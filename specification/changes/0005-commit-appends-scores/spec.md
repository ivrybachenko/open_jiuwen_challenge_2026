## Зачем

`commit_harness_version` перед прогоном стирал оба датасета. Это противоречит
контракту самих датасетов: новый `run_id` должен добавлять строку, а история
прошлых замеров — сохраняться. Из-за очистки нельзя безопасно прервать
долгий прогон, нельзя смешивать замеры разных наборов задач и теряются
результаты ручных запусков.

Дополнительно нужен способ прогнать пятикратный замер только по выбранному
набору задач, например только по новым задачам, включая нерешаемые.

## Что меняется

- `commit_harness_version` больше не удаляет строки из
  `data/harness_task_score/` и `data/harness_task_set_score/`; результаты
  дописываются.
- Появляется флаг `--tasks-from PATH`: он выбирает задачи для per-task
  прогонов из файла набора (`data/task_set/*.yaml`). Без флага используются
  все задачи под `--tasks-root`, как раньше.
- `--runs`, `--max-tasks`, `--skip-set` и `--task-set` сохраняют прежний
  смысл.

## Критерии приёмки

- [x] AC-1: если в датасете уже есть строки, после прогона они сохраняются, а
  новые строки добавляются.
- [x] AC-2: `--tasks-from` прогоняет только перечисленные задачи, включая
  задачи с `solvable: false`.
- [x] AC-3: `--max-tasks` ограничивает число задач уже после выбора через
  `--tasks-from`.
- [x] AC-4: печать прогона указывает выбранный набор и число задач.

## Вне рамок

- Изменение формата TSV-датасетов.
- Дедупликация или удаление старых строк.
- Изменение поведения `harness_task_checker` и `harness_task_set_checker`.

## Ограничения

Скрипт остаётся инструментом измерения и требует `LLM_API_KEY`; проверка без
LLM использует подменный `run_agent`, как в существующем тесте.

## Проверка

- `python -m unittest discover -s evaluation/test -t .` — быстрые тесты,
  включая сохранение старых строк и фильтр `--tasks-from`.
- Ручная проверка: запуск с `--tasks-from data/task_set/new_tasks.yaml`
  дописывает строки, не удаляя прежние.

## Риски и откат

Риск: датасет начнёт накапливать строки от неудачных прогонов. Это осознанно:
строки различаются `run_id`, а ошибочные замеры можно отфильтровать. Откат —
вернуть очистку и убрать `--tasks-from`; данные не пострадают, потому что
старые строки сохраняются.
