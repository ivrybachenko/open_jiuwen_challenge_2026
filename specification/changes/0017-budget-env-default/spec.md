## Зачем

Регламент передаёт лимит токенов окружением, а не флагом. Сейчас харнесс
читает `BUDGET` только как один из трёх псевдонимов, а без переменной работает
без лимита. Тогда прогон без явного бюджета не останавливается по расходу и
может выйти за пределы, которые организаторы считают фиксированными.

## Что меняется

1. Лимит токенов читается из переменной окружения `BUDGET`.
2. Если `BUDGET` не задана, лимит равен 100 000 выходных токенов.
3. `--budget` по-прежнему перекрывает переменную окружения.
4. Прежние псевдонимы `TOKEN_BUDGET` и `LLM_TOKEN_BUDGET` больше не читаются:
   бюджет задаётся только `BUDGET` или флагом.
5. Логи, `solutions.json` и остановка по бюджету не меняются.

## Критерии приёмки

- [x] AC-1: без `BUDGET` и без `--budget` настройки содержат бюджет 100 000.
- [x] AC-2: `BUDGET=<N>` задаёт бюджет `N`.
- [x] AC-3: `--budget <M>` перекрывает `BUDGET=<N>`.
- [x] AC-4: `TOKEN_BUDGET` и `LLM_TOKEN_BUDGET` не влияют на бюджет.
- [x] AC-5: README, `evaluation/README.md` и `specification/behavior/`
      называют `BUDGET` и лимит по умолчанию.

## Вне рамок

- Изменение формулы стоимости и момента остановки по бюджету.
- Изменение лимитов волн, отбора второй волны и промпта агента.
- Передача бюджета агенту: агент по-прежнему его не видит.

## Ограничения

- `--budget` остаётся для локальных прогонов и оценщиков.
- Бюджет измеряется в выходных токенах по формуле
  `output_tokens + ceil(input_tokens / 10)`.
- Бюджет `0` — валидное значение и означает немедленную остановку.

## Проверка

- `cd harness && uv run python -m unittest test.test_config test.test_token_cost`.
- Наблюдение: строка `loaded ... budget=100000` в логе без `BUDGET` и
  `budget=55000` при `BUDGET=55000`.
- Результат проверки фиксируется в этом файле после выполнения задач.

Результат: `unittest discover -s test` — 60 тестов OK (включая
`BudgetSettingsTest`). Прямой вызов `Settings.from_env` дал `100000` без
`BUDGET`, `55000` при `BUDGET=55000` и `8000` при `--budget 8000`. Строка
`TOKEN_BUDGET`/`LLM_TOKEN_BUDGET` в коде осталась только в тесте, который
проверяет, что псевдонимы игнорируются.

## Риски и откат

- Локальные прогоны без бюджета теперь ограничены 100 000 токенов. Для
  неограниченного прогона нужно передать заведомо большой `--budget`.
- Откат: вернуть чтение псевдонимов и `budget=None` при отсутствии переменной.
