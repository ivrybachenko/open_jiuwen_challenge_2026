## Зачем

Две волны обрезают агента на середине работы. Замеры на `example` (версия
`0003`, `qwen3.6-35b-a3b-noreason`, по 3–5 прогонов на задачу):

- `search_0001`: за 2 хода 0/5; за 4 хода 3/3, 430–435 токенов.
- `search_0005` (два перехода): за 2 хода 0/5; за 4 хода 1/3; за 5–6 ходов
  3/3, 659–901 токенов.
- `coding_0003`: за 2 хода 3/5; за 4 хода 3/3.

Ход тратится на одну команду (`grep`, затем `cat`, затем ещё `grep`), потому
что модель без ризонинга почти не склеивает зависимые шаги в один скрипт.
Выходных токенов на ход мало (16–50), лимит `wave1_max_tokens` не при чём:
ограничение — число ходов, а не размер ответа.

Ризонинг проверялся отдельно: `qwen3.8-27b` за 2 хода решает `coding_0003`
3/3, но `search_0005` только 1/3 и стоит в 1,5–3 раза дороже. Решено оставить
модель без ризонинга и добавить ходы.

## Что меняется

1. Появляется параметр `--max-waves` / `HARNESS_MAX_WAVES`, по умолчанию 4.
   Харнесс выполняет волну 1 для всех задач, затем волны 2–`max_waves` только
   для задач без пригодного ответа.
2. Каждая следующая волна выбирает кандидатов тем же предсказателем
   вероятности и тем же лимитом задач (`wave2_max_tasks`); бюджет проверяется
   перед каждым ходом.
3. Волны 3 и 4 используют ту же модель, что и вторая (`--wave2-model`, по
   умолчанию основная модель без ризонинга), и лимит `wave2_max_tokens`.
4. На последней разрешённой волне предупреждение агенту говорит, что попытка
   финальная: нужно совместить оставшиеся команды и записать `answer.txt` в
   том же скрипте.
5. Признак «волна выполнена» хранится в истории ходов, поэтому повторный
   запуск процесса не повторяет уже сделанные волны.

## Критерии приёмки

- [x] AC-1: без флага и переменной `max_waves=4`; `--max-waves` и
      `HARNESS_MAX_WAVES` перекрывают значение, флаг приоритетнее.
- [x] AC-2: CLI выполняет волны 2…`max_waves` и останавливается при
      исчерпании бюджета, ошибках модели или отсутствии кандидатов.
- [x] AC-3: `run_turn` поддерживает волну 3 и 4, отмечает её выполненной и на
      последней волне добавляет требование финальной сдачи.
- [x] AC-4: модель по умолчанию остаётся `qwen3.6-35b-a3b-noreason`;
      ризонинг не включается автоматически.
- [x] AC-5: юнит-тесты проходят; 5 замеров набора `example` на версии `0004`
      записаны в `data/harness_task_set_score/harness_v_0004.tsv`.

## Вне рамок

- Проверка видимых тестов после хода и повтор при неправильном `DONE`. Это
  отдельное изменение контракта «solved = ответ сдан».
- Автоматическая сдача ответа харнессом.
- Ризонинг и смена модели по волнам.
- Пятая волна: по замеру `search_0005` иногда требует 5 ходов, но решение
  ограничено четырьмя волнами.

## Ограничения

- Каждая волна повторяет обзор и историю, поэтому стоит ~150–400 токенов на
  поисковую задачу; на `example` ожидается рост стоимости примерно с 2,3 до
  3–4 тыс. токенов.
- Отбор не отличает «модель исследовала» от «модель ошиблась»: задача с
  неверным `answer.txt` не переотбирается.
- `search_0005` с двумя переходами может остаться нерешённой и за 4 волны.

## Проверка

- `cd harness && uv run python -m unittest discover -s test` — 74 теста OK.
- 5 × `python -m evaluation.harness_task_set_checker --task-set
  data/task_set/example.yaml --harness-version 0004 --record`.
- Сравнение с `harness_v_0003.tsv` по баллам и токенам.

Результат: 5 прогонов дали 18, 18, 17, 16, 18 (среднее 17,4) при стоимости
2853–3087 токенов (среднее 2995). Версия `0003`: 15–17 (среднее 16,2) при
2064–2627 (среднее 2328). `search_0001` теперь решается в 4 прогонах из 5
(было 0/5), `coding_0003` — 4/5. `search_0005` по-прежнему 0/5: даже на
финальном ходу модель читает файл и не пишет `answer.txt`; задаче нужно
пятое действие. Три контейнерных прогона на Linux дали 17/20 каждый.

## Риски и откат

- Стоимость растёт на всех незавершённых задачах, а не только на перспективных.
  Отбор и проверка остатка бюджета ограничивают расход; при необходимости
  `--max-waves 2` возвращает прежнее поведение.
- Четыре волны могут тратить ходы на задачи, где модель уже исчерпала подход.
  Ограничение `wave2_max_tasks` и порог обещания снижают риск.
- Откат: `--max-waves 2` без изменения кода.
