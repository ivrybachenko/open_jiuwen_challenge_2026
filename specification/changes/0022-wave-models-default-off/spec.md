## Зачем

Изменение `0021` включило модели на волны 2–4 по умолчанию. После этого
проверка на другом семействе задач (research ↔ evaluation, скрипт
`research/experiments/0012-wave-specific-models/cross_source_check.py`)
показала, что выигрыш в ранжировании не переносится:

| Переход | Волна | Модель волны, AUC | Глобальная, AUC |
| --- | ---: | ---: | ---: |
| research → evaluation | 2 | 0,36–0,41 | **0,645** |
| evaluation → research | 2 | 0,19–0,31 | 0,209 |
| research → evaluation | 3 | 0,52–0,56 | 0,518 |
| evaluation → research | 3 | 0,21–0,25 | **0,384** |

Калибровка (Brier) у моделей на волну часто лучше, но выбор задач идёт по
ранжированию `P`, а не по Brier. Живой A/B `0014` тоже не дал значимого
выигрыша. Поэтому по умолчанию должен работать проверенный глобальный
предиктор, а модели на волну остаются экспериментальными и включаются
явно.

## Что меняется

1. `HARNESS_WAVE_MODELS` по умолчанию `0` (выключены). Глобальная модель
   используется на всех волнах.
2. `HARNESS_WAVE_MODELS=1` (или `true`/`on`/`yes`) включает модели на волны
   2–4 и модель волны 4 для 5+.
3. Артефакты `wave_models.joblib` и `wave_model.json` остаются в образе:
   их можно включить без пересборки и переобучения.
4. Формула отбора, бюджет и лимиты не меняются.
5. Исправление `timed_out`/`script_error` из `0021` сохраняется: это
   исправление входа модели, не зависящее от волновых моделей.

## Ограничения

- Кросс-источниковая проверка маленькая: 3 задачи на волнах 2/3 в
  evaluation. Она не доказывает, что модели на волну бесполезны навсегда;
  она показывает, что текущего подтверждения недостаточно для default on.
- Глобальная модель тоже слабо ранжирует кандидатов (AUC 0,50–0,65 в
  зависимости от набора); это отдельная проблема.

## Проверка

- `cd harness && uv run python -m unittest discover -s test` — все тесты.
- `cross_source_check.py` — таблица выше.
- `HARNESS_WAVE_MODELS=1` — дымовой прогон `example` с включёнными
  моделями; `HARNESS_WAVE_MODELS=0` — обычный прогон.
- Результат: default off; глобальная модель используется во всех волнах,
  если переменная не задана.

## Риски и откат

- Риск: если на скрытом наборе волновые модели всё же лучше, default off
  упустит выигрыш; включаются одной переменной без пересборки.
- Риск: глобальная модель плохо ранжирует кандидатов; это не решается
  текущими волновыми моделями, нужен новый сбор данных.
- Откат: `HARNESS_WAVE_MODELS=1`.
