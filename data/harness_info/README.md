# harness_info

Версии харнесса и их происхождение. Один файл — `harness_info.tsv`, по одной
строке на версию.

| Поле | Описание |
| --- | --- |
| `harness_version` | Версия из `harness/pyproject.toml` (`[project].version`), например `0001`. Нумерация целочисленная, без SemVer. |
| `parent_harness_version` | Версия, от которой сделана эта; для первой версии — `0000`. |
| `description` | Короткое описание изменений версии. |

Формат — TSV (поля разделены табуляцией), кодировка UTF-8. Существующие
описания не перезаписываются автоматически: их правят руками.

Строка для текущей версии добавляется автоматически при запуске одиночного
чекера с флагом `--record`, если её ещё нет:

```bash
python -m evaluation.harness_task_checker \
    --task coding/easy/0001 --harness-version 0001 --record
```

Полный замер версии (`commit_harness_version`) требует, чтобы запись уже
существовала: если версии нет в таблице, скрипт завершается ошибкой и ничего
не пишет в score-датасеты. Версия берётся из `harness/pyproject.toml`; флаг
`--harness-version` должен с ней совпадать.
