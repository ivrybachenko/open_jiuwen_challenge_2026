# Генератор решаемых задач

Скрипты создают задачи `data/task/<category>/solvable/0007`–`0040` — по 34
новые задачи в каждой категории. Вместе с исходными и нерешаемыми задачами
получается 240 задач: по 60 в каждой категории, из них 40 решаемых и 20
нерешаемых. Нерешаемые `impossible/0011`–`0020` написаны вручную и не
генерируются.

```bash
cd data/task_generation
python3 generate.py
```

Генератор перезаписывает только каталоги `solvable/0007`–`0040` и наборы
`data/task_set/train.yaml`, `data/task_set/new_tasks.yaml`. Примеры
организаторов и нерешаемые задачи не меняются.

## Проверки при генерации

- Задачи с `unittest` проверяются дважды: исходный файл должен проваливать
  тесты, эталонная реализация — проходить. Тесты лежат в рабочем каталоге.
- Задачи с `hidden_unittest` проверяются так же, но тесты лежат в
  `<task>/tests/`, вне рабочего каталога агента.
- Для задач с `exact_int` и `exact_str` ожидаемый ответ вычисляется из
  сгенерированных данных, а не вводится вручную.
- Генерация детерминирована: одни и те же данные и ответы получаются при
  повторном запуске.
- Баллы новых задач перемешиваются отдельно от типа задачи и её сложности:
  `reward` не подсказывает, простая задача или сложная.
- Нерешаемые задачи `impossible/0011`–`0020` не генерируются. Для них
  проверены формат `task.json`, наличие `workspace/` и падение исходного
  состояния тестов в `coding`.

## Структура

| Файл | Что создаёт |
| --- | --- |
| `common.py` | запись задачи, запуск тестов, проверка эталона |
| `coding.py` | 34 задачи по программированию |
| `math_tasks.py` | 34 математические задачи |
| `data_analysis_tasks.py` | 34 задачи по анализу данных |
| `search_tasks.py` | 34 задачи по поиску в файлах |
| `generate.py` | запуск всех генераторов и обновление наборов |
